# Wanderlust

Wanderlust is a full-stack travel listing web application where users can explore, create, edit, and manage travel listings.

## Features

- User registration and login
- User authentication and authorization
- Create, view, edit, and delete listings
- Image upload for listings
- Review and rating system
- Flash messages and error handling
- Responsive web interface

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- EJS
- JavaScript
- Bootstrap
- Passport.js
